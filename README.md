# Epic Airplane — Unity Rebuild Starter

هذا المستودع يحتوي على ملفات تأسيسية لإعادة بناء لعبة الطائرة في Unity اعتمادًا على تحليل الأصول المستخرجة من APK.

> **الحالة:** يحتوي المشروع على نموذج تشغيل أولي وخمسة ملفات GLB. أضيفت حزمة glTFast وأداة Editor لتوليد Prefabs، لكن لم يتم التحقق من فتح المشروع أو تشغيله داخل Unity حتى الآن.

## البيئة المستهدفة
- Unity 2022.3.62f3
- مشروع 3D Core

## البنية
- `Assets/Models/GLB/` — ملفات النماذج الخمسة.
- `Assets/Editor/GenerateAirplanePrefabs.cs` — أداة إنشاء Prefabs بعد استيراد ملفات GLB.
- `Assets/Resources/Airplanes/` — المجلد الذي ستنشأ فيه Prefabs القابلة للتحميل وقت التشغيل.
- `Assets/Prefabs/Airplanes/` — مساحة تنظيم إضافية للـ Prefabs التي لا تحتاج إلى Resources.
- `Assets/Scripts/Airplane/` — نظام مراحل تطوير الطائرة.
- `Assets/Scripts/Flight/` — سكربتات نموذج المقلاع.
- `Assets/Scenes/Main.unity` — مشهد النموذج الأولي.

## النماذج المضافة
| ملف GLB | الاسم المقترح للـ Prefab |
|---|---|
| `plane_pc.glb` | `PlayerPlane` |
| `dae_stylized_plane_comet_88.glb` | `EnemyComet` |
| `stylized_ww1_plane.glb` | `EnemyWW1` |
| `medium_haul_plane_low_poly.glb` | `HeavyPlane` |
| `overlordchaoss_plane_as_a.glb` | `BossPlane` |

هذه أسماء وأدوار مقترحة حسب أسماء الملفات فقط؛ لم يتم فحص أشكال المجسمات داخل Unity للتأكد من ملاءمتها البصرية.

## إعداد واستيراد GLB
1. افتح المشروع في Unity 2022.3.62f3 أو إصدار 2022.3 متوافق، وانتظر انتهاء Package Manager من تثبيت `com.unity.cloud.gltfast` وانتهاء استيراد الملفات.
2. تأكد من عدم وجود أخطاء استيراد في نافذة Console.
3. من القائمة اختر `Tools > Epic Airplane > Generate Airplane Prefabs`.
4. راجع Console؛ يجب أن تؤكد الأداة عدد الـ Prefabs التي أنشأتها. إذا تعذر تحميل ملف GLB كـ GameObject، لا تعتبر ذلك الملف مستوردًا بنجاح.
5. شغّل المشهد `Assets/Scenes/Main.unity`. سيحمّل النموذج الأولي `Resources/Airplanes/PlayerPlane` إن كان قد تم توليده؛ وإلا سيستخدم شكل الطائرة المؤقت.

الأداة تنشئ أغلفة Prefab، وتضبط حجم كل نموذج تقريبيًا وتضيف BoxCollider من حدود المجسم. هذه الحدود تقريبية ويجب مراجعتها بصريًا وفي الفيزياء.

## إعداد المشروع
1. افتح مجلد المستودع من Unity Hub.
2. انتظر تثبيت الحزم والاستيراد الكامل.
3. شغّل أداة توليد الـ Prefabs من قائمة Tools.
4. اختبر المقياس والاتجاه والخامات والتصادمات في المحرر.
5. اربط Prefabs الأعداء والزعيم بمنطق اللعب والمشاهد بعد اختبارها؛ وجود ملفات Prefab وحده لا ينشئ سلوك أعداء تلقائيًا.

## حالة النموذج الأولي
- ينشئ `RuntimePrototypeBootstrap.cs` أرضية وإضاءة وكاميرا وطائرة عند تشغيل المشهد.
- يمكن سحب الطائرة وإفلاتها لإطلاقها، وتوجد إعادة ضبط تلقائية وزر إعادة ضبط.
- عند توفر `PlayerPlane.prefab` يستخدم النموذج المستورد؛ وإلا يعود إلى الشكل الهندسي المؤقت.
- أُنشئت أداة تجهيز Prefabs للأدوار الخمسة، لكن يجب تشغيلها داخل Unity Editor.
- لم يتم فتح المشروع أو التحقق من C# compilation أو تشغيله أو بناء APK؛ لا تعتبر هذه المراحل ناجحة قبل تنفيذها فعليًا.

## ملاحظات
- هذا مشروع إعادة بناء أولي وليس نسخة مطابقة أو كاملة من اللعبة الأصلية.
- ملفات APK والأصول المستخرجة قد تخضع لحقوق نشر؛ تأكد من حقك في استخدامها ومشاركتها.
- لا ترفع أسرارًا أو مفاتيح وصول إلى المستودع.
